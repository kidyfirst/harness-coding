# Harness Spec Instructions

These instructions are for AI assistants working in this project.

This project is managed by `harness-spec`. The working knowledge you need lives under `{{WORKFLOW_ROOT}}/`:

- `{{WORKFLOW_ROOT}}/workflow.md` — development phases, when to create tasks, skill routing
- `{{WORKFLOW_ROOT}}/spec/` — package- and layer-scoped coding guidelines
- `{{WORKFLOW_ROOT}}/workspace/` — project-owner session journals and traces
- `{{WORKFLOW_ROOT}}/tasks/` — active and archived tasks, PRDs, research, and context

If a Harness command is available on your platform, prefer it over manual steps. Not every platform exposes every command in the same way.

If you're using Codex or another agent-capable tool, additional project-scoped helpers may live in:
- `.agents/skills/` — reusable Harness skills
- `.codex/agents/` — optional custom subagents
